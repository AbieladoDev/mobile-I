# Aula 02 - Misturando clique() e sortear()

Lista de exercícios da disciplina de Mobile. Cada pasta é um exercício
separado, feito em Kotlin usando android:onClick no layout.

## Exercícios

- **exercicio1** - Botão "Saudar": imprime no Logcat e atualiza o TextView na mesma função.
- **exercicio2** - Contador de cliques com a variável declarada fora da função.
- **exercicio3** - Sorteio de 0 a 10 avisando no Logcat se o número é par ou ímpar.
- **exercicio4** - Dado de 1 a 6 com contagem de rolagens ("Rolagem 3: resultado 5").
- **exercicio5** - Três botões: um só avisa, um só sorteia e um faz as duas coisas.
- **exercicio6** - Sorteio mudando a cor do texto conforme par ou ímpar (setTextColor).

## Como rodar

Abrir cada pasta como projeto no Android Studio e rodar no emulador.
As mensagens aparecem no Logcat (filtro System.out).
